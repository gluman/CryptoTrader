# Снапшот скриптов Hermes

Боевые копии живут в `~/.hermes/scripts/` — **оттуда их запускает cron**, и правки
нужно вносить именно там. Здесь снапшот для версионирования: сами по себе эти
файлы ничего не запускают.

## Зачем

Скрипты формируют все Telegram-отчёты и обновляют часовые данные, но не были
под контролем версий: откатить неудачную правку было не к чему. При этом в
проекте уже случался разъезд копий — `multi_strategy_monitor.py` существовал
и здесь, и в `~/.hermes/scripts/`, файлы отличались, а cron запускал версию из
`.hermes`, из-за чего правки «не применялись».

## Как не разъехаться

Снапшот обновлять вместе с боевой правкой:

    cp ~/.hermes/scripts/<файл> hermes_scripts/ && git add hermes_scripts/

Надёжнее — перевести боевые пути на симлинки сюда, тогда источник останется
один. Не сделано: меняет рабочую конфигурацию Hermes, нужно решение владельца.
