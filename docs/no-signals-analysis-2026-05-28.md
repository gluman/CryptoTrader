## 3 корневые причины

### 1. ГЛАВНАЯ: Volume Gate убивает все сигналы

Решающий цикл (`/tools/decide/run`) работает каждые 15 мин через API (`POST /tools/decide/run`). Но ВСЕ символы отбрасываются фильтром `vol_gate` ещё до LLM:

```
XRPUSDT: vol_gate HOLD (volume_ratio 0.33 < 0.5)
DOGEUSDT: vol_gate HOLD (volume_ratio 0.32 < 0.5)
TONUSDT: vol_gate HOLD (volume_ratio 0.44 < 0.5)
```

**Порог:** `volume_ratio >= 0.5` (конфигурируемый)
**Реальность:** volume_ratio у всех 0.02–0.44. Рынок в глубоком штиле.

Из ~50 вызовов decide за сутки только 2–3 раза TON прошёл гейт.

### 2. Execution крашится на каждом сигнале

Даже когда сигнал проходит volume gate, execution agent падает:
```
[Execution] Execution failed signal 81: 'Config' object has no attribute 'risk'
[Execution] Execution failed signal 82: 'Config' object has no attribute 'risk'
```

**Причина:** В конфиге отсутствует секция `risk`. Execution agent не может рассчитать размер позиции и SL/TP.

### 3. API в crash-loop

Два процесса `--task api` (PID 209668 и 236251) одновременно перезапускаются каждые ~15 сек, борясь за порт 8000. Это не ломает работу (один успевает обработать запросы), но засирает логи и жёрт процессор (PID 236251 ест 102% CPU).
